# Network testing

Test on actual devices where possible. Browser throttling approximates network constraints but cannot reproduce every device or carrier condition.

Suggested scenarios:
- Slow initial load
- High latency and intermittent packet loss
- Connection loss during form entry
- Connection loss during submission
- Recovery after refresh and restart

Tools: [Chrome DevTools](https://developer.chrome.com/docs/devtools/), [Lighthouse](https://github.com/GoogleChrome/lighthouse), [WebPageTest](https://www.webpagetest.org/).
