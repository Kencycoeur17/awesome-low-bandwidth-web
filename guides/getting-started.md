# Getting started

1. Establish a baseline on a real or throttled mobile connection.
2. Identify the largest resources and slowest interactions.
3. Set an explicit performance budget.
4. Handle offline, timeout, and retry states.
5. Test a complete user journey rather than only a landing page.

Useful starting points: [web.dev performance](https://web.dev/performance/), [MDN Web performance](https://developer.mozilla.org/en-US/docs/Web/Performance), and [Chrome DevTools](https://developer.chrome.com/docs/devtools/).
