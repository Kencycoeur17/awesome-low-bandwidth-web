# Contributing

Thanks for helping build a useful resource for constrained networks.

1. Search the list before proposing a duplicate.
2. Prefer official documentation, maintained tools, and reproducible research.
3. Provide a working HTTPS URL, a neutral one-sentence description, and the category.
4. Avoid affiliate links, pay-to-list requests, and unsupported performance claims.
5. Open a focused pull request. Please keep entries alphabetical within each section.

Issues and PRs should be written in English. Contributors must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
